# Конфигурационное управление — вариант №5

Учебный эмулятор командной строки UNIX-подобной ОС на Python.

## Этапы 1–3

1. REPL: консоль, имя VFS в приглашении, парсер по пробелам,
   заглушки `ls`, `cd`, команда `exit`.
2. YAML и ключи `--config`, `--vfs`, `--startup`; CLI имеет приоритет.
   Стартовый скрипт поддерживает комментарии и показывает ввод и вывод.
3. Каталог VFS считывается в память. Виртуальная файловая система
   хранит содержимое файлов и каталогов без изменений исходных данных.

## Запуск и тестирование

```sh
python3 -m pip install -r requirements.txt
./run.sh
./scripts/check_config.sh
./scripts/check_vfs.sh
python3 -m unittest discover -s tests -v
```
