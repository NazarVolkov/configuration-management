# Практическая работа № 3. Вариант 5

Ассемблер и интерпретатор для стековой учебной виртуальной машины. Проект написан на C++17 и использует
стандартную библиотеку.

## Язык ассемблера

Исходный файл в UTF-8 содержит YAML-последовательность. Каждая строка команды начинается с `- ` и задаёт
одно соответствие `имя: операнд`. Допускаются пустые строки и комментарии YAML после `#`.
Операнд записывается неотрицательным десятичным целым.

| Команда | Поле A | Поле B | Действие |
| --- | ---: | --- | --- |
| `push` | 14 | Константа 0…67108863 | Помещает константу на стек |
| `load` | 6 | Адрес 0…65535 | Помещает значение из памяти на стек |
| `store` | 3 | Адрес 0…65535 | Снимает вершину стека и сохраняет значение по адресу |
| `sqrt` | 11 | Смещение 0…65535 | Снимает число, затем базовый адрес, и записывает корень по адресу база + смещение |

Перед `sqrt` поместите на стек базовый адрес, затем число под корнем. Значение результата сохраняется в памяти
и поддерживает дробную часть. База должна быть целым числом, а сумма базы и смещения должна попадать в память.

## Сборка и проверка

Команды выполняются в PowerShell из корня проекта. Для сборки нужен MSVC с компонентом «Разработка классических
приложений на C++».

```powershell
.\build.bat
.\run.bat assemble tests\encoding.yaml build\encoding.bin --test
.\run.bat assemble tests\encoding.yaml build\encoding.bin --test-fields
.\run.bat assemble tests\copy.yaml build\copy.bin
.\run.bat interpret build\copy.bin build\copy.csv 100 103
.\run.bat assemble tests\sqrt.yaml build\sqrt.bin
.\run.bat interpret build\sqrt.bin build\sqrt.csv 256 258
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run.ps1
```

`assemble` принимает исходный файл и путь для машинного кода. Он записывает по четыре байта на команду
в порядке от младшего байта к старшему и выводит размер файла в байтах. `--test` выводит также байты команд,
а `--test-fields` показывает поля `A` и `B` каждой команды. `--help` выводит справку.

`interpret` принимает двоичный файл, путь к CSV и два адреса от `0` до `65535`. Обе границы входят в дамп.
Программа читает команды из двоичного файла, а стек и данные хранит отдельно. При запуске все 65536 ячеек содержат
ноль. CSV имеет столбцы `address,value`. Пример `copy.yaml` копирует массив `[7, 42, 513, 67108863]` из ячеек
20–23 в ячейки 100–103. Пример `sqrt.yaml` сохраняет `sqrt(144) = 12` в ячейке `250 + 7 = 257`
и `sqrt(100) = 10` в ячейке `65535`.

При ошибке программа выводит диагностику и возвращает код 1. После ошибки выполнения CSV не записывается.

## Поэлементный корень из вектора

Каждая из трёх программ записывает исходный вектор длины 6 в ячейки 10–15. Затем она читает его элементы
командой `load` и записывает результаты через `sqrt` в ячейки 20–25. В качестве базового адреса используется 20,
а смещение совпадает с индексом элемента.

| Программа | Входной вектор | Результат |
| --- | --- | --- |
| [Квадраты] | `[1, 4, 9, 16, 25, 36]` | `[1, 2, 3, 4, 5, 6]` |
| [Смешанные числа] | `[0, 2, 8, 49, 121, 256]` | `[0, √2, √8, 7, 11, 16]` |
| [Большие числа] | `[100, 1024, 10000, 1000000, 16777216, 67092481]` | `[10, 32, 100, 1000, 4096, 8191]` |

[Квадраты]: tests/vector-squares.yaml
[Смешанные числа]: tests/vector-mixed.yaml
[Большие числа]: tests/vector-large.yaml

```powershell
.\run.bat assemble tests\vector-mixed.yaml build\vector-mixed.bin
.\run.bat interpret build\vector-mixed.bin build\vector-mixed.csv 20 25
Get-Content build\vector-mixed.csv
```

`tests/run.ps1` проверяет поля и байты из спецификации, копирование массива, команду `sqrt`, диагностические
сообщения и CSV для всех трёх векторов. В векторных тестах проверяются исходный вектор, результат и ячейки между ними.

## Устройство программы

- `main.cpp` обрабатывает аргументы, запускает сборку машинного кода или интерпретацию и выводит ошибки.
- `instruction.cpp` задаёт мнемоники, коды и ширину полей. `find_operation` ищет команду по имени или коду.
- `assembler.cpp` читает YAML через `read_assembly`, проверяет синтаксис и диапазон каждого операнда.
- `machine_code.cpp` записывает программу через `write_machine_code` и читает команды через `read_instruction`.
- `interpreter.cpp` выполняет команды в `interpret`, управляет стеком, вычисляет адрес записи и сохраняет CSV.
