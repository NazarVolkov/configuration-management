# Практическая работа №2

Анализатор зависимостей пакетов NuGet на C++ для Windows, вариант 5.
Получает прямые и транзитивные зависимости, выполняет обратный поиск
и строит диаграмму PlantUML и ASCII-дерево.

Реализация находится в [Main version](Main%20version/README.md).
В этой папке есть настройки `config.json`, примеры, исходный код и проверки.
Команды сборки, запуска и тестирования приведены в README реализации.

Этапы `--stage 1–5`: чтение настроек, прямые зависимости, полный граф,
обратные зависимости и визуализация. По умолчанию выполняется этап 5.
