# Практическая работа 2. Вариант 5

Две реализации инструмента визуализации зависимостей NuGet.

| Папка | Назначение | Инструкция |
| --- | --- | --- |
| Main version | Основная реализация на C++17 | [README](Main%20version/README.md) |
| Additional version | Дополнительная реализация на Python | [README](Additional%20version/README.md) |

У каждой версии свои src, tests, настройки, примеры и run.bat.
Обе реализации используют рекурсивный DFS, обрабатывают циклы,
поддерживают обратные зависимости, PlantUML и ASCII-дерево.
Коммиты пяти этапов каждой реализации сохранены в истории.

## Запуск из папки practice2

```powershell
& ".\Main version\run.bat"
& ".\Additional version\run.bat"
```

Для работы без изображения добавьте --no-image. Сборка C++, требования
к окружению, параметры и команды тестов приведены в README каждой версии.
