# Практическая работа №2

Анализатор зависимостей пакетов NuGet, вариант 5. Получает прямые и транзитивные зависимости, выполняет обратный поиск и строит диаграмму PlantUML и ASCII-дерево.

В работе две реализации:

- [Main version](Main%20version/README.md) — основная версия на C++ для Windows.
- [Additional version](Additional%20version/README.md) — дополнительная версия на Python.

В каждой папке есть настройки `config.json`, примеры, исходный код и проверки. Команды запуска приведены в README соответствующей версии.

Этапы `--stage 1–5`: чтение настроек, прямые зависимости, полный граф, обратные зависимости и визуализация. По умолчанию выполняется этап 5.
