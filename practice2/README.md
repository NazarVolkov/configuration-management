# Практическая работа 2, вариант 5

Визуализатор зависимостей пакетов NuGet на Python 3.9+.
Для получения зависимостей используются только стандартные модули Python.
Сборка и установка библиотек не нужны.

## Этап 1: конфигурация

```powershell
.\run.bat
python -B -m unittest discover -s tests -v
```

`config.json` содержит имя пакета `package`, источник `repository`,
логический признак тестового режима `test_mode` и вывода дерева `ascii_tree`.
В тестовом режиме источник является путём относительно конфигурации,
в обычном режиме это URL индекса NuGet V3.

В тестовом репозитории имена состоят из больших латинских букв.
Неверные типы, отсутствующие параметры, неправильные имена и источники
выводятся как ошибки с ненулевым кодом завершения.

`src/config.py` проверяет настройки, `src/main.py` запускает программу,
`tests/test_config.py` проверяет обязательные параметры.

## Этап 2: прямые зависимости NuGet

```powershell
.\run.bat examples/nuget.json --stage 2
.\run.bat --stage 1
```

`src/nuget.py` читает индекс NuGet V3, список версий и XML-файл `.nuspec`
через `urllib.request` и `xml.etree.ElementTree`. Менеджеры пакетов
и библиотеки извлечения зависимостей в программе не используются.

Необязательные настройки: `version` выбирает точную версию корня,
`framework` выбирает точную группу платформы в nuspec, по умолчанию net8.0.
Автоматический подбор совместимой платформы не выполняется.
Без `version` выбирается последняя стабильная версия корня.
Для зависимостей берётся минимальная стабильная версия в заданном интервале.
Поддерживаются числовые версии, минимумы, точные ограничения `[1.0.0]`
и интервалы `[1.0.0,2.0.0)`. Предварительные и плавающие версии не поддерживаются.

## Этап 3: рекурсивный DFS

```powershell
.\run.bat --stage 3
.\run.bat examples/config_cycle.json --stage 3
.\run.bat examples/config_leaf.json --stage 3
```

`src/graph.py` строит словарь списков смежности рекурсивным DFS.
Узел добавляется в словарь до обхода его потомков: повторное посещение
останавливается, поэтому циклы и общие зависимости обрабатываются корректно.
На этом этапе выводится список рёбер. Тестовые графы: ветвление с общей
зависимостью, цикл из трёх пакетов и пакет без зависимостей.

## Этап 4: обратные зависимости

```powershell
.\run.bat --stage 4 --reverse D
.\run.bat --stage 4 --reverse A
.\run.bat examples/config_cycle.json --stage 4 --reverse B
```

`reverse_dependencies` разворачивает каждое ребро и вызывает тот же
рекурсивный `build_graph`. Для D в первом примере результат содержит
прямых потребителей B и C и косвенного потребителя A.
Без `--reverse` выбирается корневой пакет из конфигурации.

В тестовом режиме поиск выполняется по всему JSON-репозиторию.
Для NuGet поиск ограничен загруженным графом выбранного корня;
цель задаётся полным именем узла `package@version`. Поиск всех потребителей
пакета во всём интернете через NuGet V3 не выполняется.
